# VOID REALMS V5

Mobile character-adventure gameplay inspired by the control language of Roblox-style experiences, while using an original VOID REALMS world, story, combat and server architecture.

V5 focus:
- Third-person-like camera framing
- Virtual joystick movement
- Jump and interact buttons
- Character-centered adventure controls
- Original main-story tracker and dialogue
- Existing multiplayer, combat, quests, inventory and server authority retained
